# CyberSecurity
# 🛡️ Hybrid Security Dashboard
A Flask and MySQL based web application for managing security resources through a centralized dashboard.

## Features
- 🔐 User Authentication
- 📊 Dashboard Analytics
- 💻 Asset Management
- 🌐 VPC Management
- 🔒 Security Rules Management
- 🚨 Alert Monitoring
- 📋 Activity Logs

## Technologies Used
- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
